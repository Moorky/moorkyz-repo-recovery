Evidence is not a guarantee

Measurements inform estimates. Condition × relational quality / 100 is a scenario estimate; confidence is not a probability. Known-file retention is a separate measured fact.

Estimate cheatsheet

Condition: local structure (50 points) + successful Git observations (50). Unknown Git errors remain unknown. Relational recovery: reviewer-chosen value against a stated target; 100% means a 1× ratio, not certainty. Recovery: condition × ratio / 100. Example: 50% × 100% = 50%; 50% × 150% = 75%. Confidence: evidence coverage informs reviewer judgement; never multiply it into the recovery formula.

Automatic defaults: static root rubric for potential; executed checks for current quality; 20 points per completed evidence gate for confidence. Reviewer overrides need rationale. Estimates remain estimates, including at 100%.

Actual changes are restricted to the verified disposable working copy. Original and untouched backup are never overwritten. Preview first, approve exact bytes, then rerun integrity and quality.
